# ZeroPCD
Deep learning experimental work on poinclouds

## layout
```
open-point/
├── configs/
│   ├── default.yaml         # Base configurations (batch size, LR, paths)
│   └── debug.yaml           # Overrides for quick laptop testing (e.g., smaller point counts)
├── data/
│   └── raw/                 # Ignored by git; where ModelNet/nuScenes subset goes
├── src/
│   ├── __init__.py
│   ├── models/
│   │   ├── __init__.py
│   │   ├── pointnet.py      # The architecture we just drafted
│   │   └── tnet.py          # Separated T-Net logic
│   ├── data/
│   │   ├── __init__.py
│   │   └── dataset.py       # PyTorch Dataset and DataLoader logic
│   └── utils/
│       ├── __init__.py
│       ├── config.py        # YAML parsing logic
│       └── metrics.py       # Accuracy, IoU, Orthogonal loss functions
├── scripts/
│   ├── train.py             # Main training loop
│   └── evaluate.py          # Inference and testing loop
├── pyproject.toml           # Generated by uv (replaces requirements.txt)
├── .gitignore
└── README.md                # Project architecture, math details, and run instructions
```
